# C#上位机知识库规则

当用户要求在本项目中添加、更新、评估 C# / 上位机面经知识时，必须严格执行项目根目录下的 [C#上位机知识库准录与评估规范.md](../../C#上位机知识库准录与评估规范.md)：
1. 恪守“三必录、三不录”准则，严禁录入淘汰技术（如 ASP.NET WebForms、ViewState、.NET Remoting 等）。
2. 客观评定 1~5 星级重要程度，重点聚焦于：WPF 与跨线程、工业通信（Modbus/串口/Socket）、多线程（Channel/Task/锁）、CLR 内存与 GC、工业相机与视觉及底层 P/Invoke。
3. 遵循标准化录入格式：包含“💡 30秒速记提纲”、“🔍 深入原理解析”、“🛠️ 上位机实战避坑”与“⚠️ 常见连环追问”。
4. 保持 Markdown 底稿与 Web 自测系统的题库数据同步更新。
